# Preprocessing task 

## extraction de connaissance - data preprocessing : 

- Data preprocessing includes data preparation, coumpunded by integration cleaning, normalizaion and transformation of data; and data reduction tasks such as feature selection,instance selection, discretization, etc..
- the expected result : final dataset which can be considered correct and useful for further data mining algorithms 
- we refer to data preparation as the set of techniques that initialize the data properly to serve as input for a certain DM algorithm
- data reduction : the set of techniques that obtain a reduced representation of the original data. 

### data preprocessing : 
- Sampling 
- data preparation(cleaning,integration)
- Data transformation(transformation,normalization)
- Unbalanced data: downsampling,upweighting
- Feature engineering(...dimentionality reduction)
- spliting 

### qualite d'un dataset : 
---
- la cle d'un bon modele de machine learning est la qualite des donnees utilisees pour l'entrainer. 
- Il est utile dans la collection de donnees d'avoir une definition plus concrete de la qualite, de facon generale , un bon data set doit repondre a 3 contraintes : 
1. fiabilite
2. representation de caracteristiques
3. reduction du bias 

### fiabilite : 
- un modele forme a partir d'un ensemble de donnees fiables(degre auquel on peut faire confiance aux donnees) est plus susceptible de produire des prediction utiles qu'un modele forme a partir de donnees non fiables. La mesure de fiabilite permet d'avoir une visibilite sur les performances. Pour y arriver, il fault savoir : 
1. Quelle est la frequence des erreurs d'etiquetage? Par exemple, si vos donnees sont etiquetees par des humains, ils commettent parfois des erreurs.
2. vos caracteristiques sont-elle bruyantes ? 
- on ne peut jamais avoir un ensemble de donnees sans bruit. Un peu de bruit est acceptable. 
3. Les donnees sont-elles correctement filtrees pour le probleme? 
- par exemple ? requetes de recherche de robots pour la detection de spam mais pas dans d'autre contexte. 

- ce qui rend un dataset non fiable : validité;precision; complétude;cohérence: 
### 1.validité : 
- les types de donnees : les valeurs d'une colonne doivent etre d'un type de donnees particulier, par exemple numerique , categorique .. 
- contraintes de plage : les nombres doivent etre compris par une plage donnee
- contraintes obligatoire : certains donnee ne peuvent pas etre vide 
- unicite : un champ ou plusieurs champs combines doit etre unique dans un data set. 
- bonne etiquettes

### 2.precision : 
- Cette tâche n’est clairement pas simple. Car définir toutes les valeurs valides
possibles permet de repérer facilement les valeurs non valides, cela ne
signifie pas pour autant qu’elles sont exactes et encore moins qu’elles sont
précises.
- La différence entre exactitude et validité : Par exemple, dire que vous vivez en
Afrique est, certes, vrai. Cependant, cette réponse n’est pas précise.

### 3.completude : 

- presence des valeurs manquantes 
### 4. coherence : 
1. donnees en double : par exemple, un serveur a telecharge deux fois par erreur les memes jornaux 
2. donnees intentionnelles : quelqu0un a tape un chiffre supplementaire ou un thermometre a ete laisse au soleil 
3. Donnees incompatibles : age et date de naissance

## Reduction du biais : 
- le biais : distance entre le meilleur modele pouvant etre appris par l'algorithme et le vrai modele. En machine learning, on cherche en general, un equilibre entre biais et variance de telle sorte que ces deux erreurs soient a peu pres egales. 

## data set size : 
- en generale, un modele doit s'entrainer sur au moins un ordre de grandeur superieur a celui des parametres pouvant etre formes. 
- les modeles simples sur de grands ensembles de donnees sont generalement plus efficaces que les modeles sophistiques sur de petits ensembles de donnees. 
- il est souvent difficile de collecter suffisamment de donnees pour un projet de ML. mais parfois cependant, il y a trop de donnees, et vous devez selectionner un sous ensemle d'exemples pour l'apprentissage.

### sampling data : types 
---
- echantillonnage aleatoire simple : il y a une probabilite egale de selectionner un element particulier 
- echantillonnage sans remplacement : au fur et a mesure que chaque element est selectionne, il est retire de la population 
- echantillionnage avec remise 
- ecchantillonnage stratifie : diviser les donnees en plusieurs paritions ; puis tirer des echantillons aleatoires de chaque cloison
