### How do you approach cleaning and preparing a messy dataset?
- when facing a messing dataset, I always follow a structured methodology to ensure data quality and reproducibility. I start with EDA checking schema types , identifying duplicate rows, and examining value distributions to understand what normal looks like. Next, I address missing values and outliers. Depending on the context, I'll decide whether to drop nulls or impute t hem usingg statistical measures like the median or domain-specific rules, while trating outliers based on statistical thresholds like IQR rather than just deleting them blindly, After that I focus on standardization-- formating dates fixing text inconsistencies, encoding categorical variables, and scaling numeric features appropriately for downstream modeling. Finally, I make sure the entire process is modularized into reusable Python functions or SQL queries so that the pipeline can run automatically whenever fresh data comes in. 
- Face à un jeu de données désordonné, je suis toujours une méthodologie structurée pour garantir la qualité et la reproductibilité des données. Je commence par une analyse exploratoire pour vérifier les types de variables, identifier les doublons et analyser les distributions pour bien comprendre la structure de départ. Ensuite, je traite les valeurs manquantes et les données aberrantes. Selon le contexte métier, je décide d'imputer les nuls—par exemple via la médiane ou des règles statistiques—ou de les supprimer, tout en traitant les outliers selon des seuils comme l'écart interquartile sans les éliminer aveuglément. Après cette phase, je passe à la standardisation : harmonisation des formats de dates, correction des chaînes de caractères, encodage des variables catégorielles et mise à l'échelle des variables numériques. Enfin, je veille à ce que l'ensemble du processus soit modularisé sous forme de fonctions Python ou de requêtes SQL pour que le pipeline de nettoyage s'exécute automatiquement sur de nouvelles données.
### What’s the difference between data science and data analytics (or data engineering) in your view?
- the main difference comes down to the scope, the timeframe and the tools used. Data analysis focuses primarily on examining historical data to answer specific business questionts and explain past trends. A data analyst uses tools like SQL, Excel , and BI platforms like Poer BI to perform descriptive analytics, build dashboards and help stakeholders make informed decisions based on what has already happened.
- Data science goes a step further by using advanced statitics, python and machine learning to forecast future trends and build automated decision systems, As a data scientistt you dont just analyze past metrics -- you build predictive models , run clustering algorithms , and engineer scalable pipelines so models can interact with software systems. In short, data analysis tells you what happende and why, while data science builds the intelligent tools to predict what will happen next and to optimize for it.
